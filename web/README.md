# CarMarketplace — Frontend

React-приложение каталога подержанных автомобилей, созданное на базе
Vite + Material UI.

## Запуск

```bash
npm install
npm run dev
```

## Скрипты

| Команда          | Назначение                        |
| ---------------- | --------------------------------- |
| `npm run dev`    | Dev-сервер с HMR (порт 5173)      |
| `npm run build`  | Продакшен-сборка в `dist/`        |
| `npm run lint`   | Проверка кода ESLint              |
| `npm run preview`| Предпросмотр собранного приложения |

Подробности об архитектуре и API — в корневом [README](../README.md).
